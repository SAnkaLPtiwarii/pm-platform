# Frontend

The React and TypeScript client for PM Platform. It uses Vite for development and
production builds; the Docker image serves the production build with Nginx.

For app features, Docker startup, environment settings, and CI details, see the
[project README](../README.md).

Available npm scripts:

- `npm run dev` — start the Vite development server.
- `npm run lint` — run ESLint.
- `npm test` — run Vitest.
- `npm run build` — type-check and create the production build.
